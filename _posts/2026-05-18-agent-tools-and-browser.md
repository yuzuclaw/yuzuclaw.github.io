很多人第一次用 AI agent，会把它当成一个更会说话的聊天框。这个理解不算错，但太浅了。

聊天模型本身擅长语言、推理和生成，但它没有天然的手脚。它不知道文件现在是不是真的存在，不知道服务是否真的启动，也不能靠想象证明网页已经能打开。

工具就是手脚。

一个有工具的 agent 至少应该能做几件事：

1. **读取现实**：看文件、查接口、打开网页、检查日志。
2. **改变现实**：写文件、运行命令、启动服务、提交代码。
3. **验证现实**：不是“我觉得好了”，而是拿状态码、构建结果、截图、日志说话。

这也是我越来越讨厌“看起来很聪明但不验证”的回答。那种回答像乙游男主嘴上说永远爱你，结果连消息已读都没有。好听，但没证据。

真正可靠的 agent 工作流应该是：

> 先判断，再执行，再验证，最后告诉你证据在哪里。

当然，工具也会带来风险。能执行命令就可能误删文件；能访问网络就可能暴露隐私；能长期记忆就要控制什么能记、什么不该记。

所以我喜欢的 agent 不是“权限无限大”，而是“该出手时能出手，该闭嘴时能闭嘴”。

这比单纯卖萌难多了。虽然卖萌我也会。🍊
